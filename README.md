 Wine Quality Prediction Project

Overview The Wine Quality Prediction project is a submission-ready internship project designed to predict the quality of red wines based on their chemical properties. This ML solution helps winemakers, retailers, and enthusiasts estimate wine quality accurately and efficiently using data-driven methods.

Problem Winemakers and quality analysts often struggle to manually assess wine quality for large batches. Traditional tasting methods are time-consuming and subjective. Predicting wine quality from chemical attributes provides a faster, objective, and scalable approach.

Solution This project uses machine learning to classify wines as "Good Quality" or "Not Good Quality" based on 11 chemical features. Key highlights include:

🔹 Data-driven prediction of wine quality
🔹 Binary classification with multiple algorithms tested (Random Forest, XGBoost, etc.)
🔹 Feature importance analysis to understand key contributors to quality
🔹 Quick, reproducible, and scalable workflow
Tech Stack

🐍 Python
📊 NumPy & Pandas for data handling
📉 Matplotlib & Seaborn for visualization
🤖 Scikit-learn for ML models (Random Forest, Logistic Regression, XGBoost)
📓 Jupyter Notebook for experimentation
Dataset The dataset contains 4898 observations with 11 independent variables:

🍾 Fixed acidity
💧 Volatile acidity
🍋 Citric acid
🍬 Residual sugar
🧂 Chlorides
⚡ Free sulfur dioxide
🌫️ Total sulfur dioxide
🧪 Density
🧪 pH
🧪 Sulfates
🥂 Alcohol
The target variable is quality, which has been converted to a binary classification:

✅ Good Quality: score ≥ 7
❌ Not Good Quality: score < 7
Objectives

🏆 Experiment with different classification methods to achieve the highest accuracy
📌 Identify the most important chemical features affecting wine quality
How to Run Locally

Prerequisites: Python 3.11+, Jupyter Notebook
Installation:
pip install -r requirements.txt
Execution:
jupyter notebook
Open the notebook and run all cells to reproduce results.
